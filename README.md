# Веб-платформа для подбора парфюмерии (Frontend)

Платформа для персонализированного подбора парфюма на основе предпочтений пользователя (ноты, бренд, пол), с каталогом товаров, корзиной, оформлением заказов и личным кабинетом.

## Demo

Проект доступен по ссылке:  https://sillage-two.vercel.app/

## Технологии

- React
- Redux Toolkit
- React Router
- SCSS
- Vite

##  Архитектура проекта

- SPA-приложение с разделением на страницы и переиспользуемыми компонентами
- Использование **Redux Toolkit** для управления глобальным состоянием:
  - корзина
  - пользователь
  - фильтры
  - заказы
  и пр.
- Асинхронные запросы к API через Redux Toolkit (createAsyncThunk)

## Реализованный функционал

- Базовая структура проекта (assets / components / routes / features)
- Маршрутизация (React Router)
- Верстка основных страниц по макетам
- Каталог парфюмерии с фильтрацией
- Персонализированный подбор парфюма на основе анкеты пользователя
- Корзина с изменением количества товаров
- Оформление заказа
- Личный кабинет пользователя
- Административная панель
- Система отзывов

## Работа с API

- Получение данных через REST API
- Использование Redux Toolkit async thunks для запросов
- Обработка состояний:
  - loading
  - success
  - error

## Особенности проекта

- Управление состоянием через Redux Toolkit
- Масштабируемая, модульная структура проекта
- Разделение логики и UI-компонентов
- Реализация реального e-commerce сценария

## Примечание

Проект разработан как учебно-практическое SPA-приложение, приближенное к реальным бизнес-сценариям e-commerce платформ.
