# Веб-платформа для подбора парфюмерии (Frontend)

Фронтенд-часть дипломного проекта. Веб-платформа для персонализированного подбора и продажи парфюмерии.

## Технологии

- React
- Redux Toolkit
- React Router
- SCSS
- Vite

## Реализовано

- Базовая структура проекта
- Маршрутизация (React Router)
- Верстка основных страниц по макетам
- Каталог парфюмерии

## В процессе

- Фильтрация по нотам, брендам, полу
- Корзина и оформление заказа
- Личный кабинет пользователя

## Планируется

- Персонализированный подбор на основе предпочтений
- Интеграция с бэкендом (в разработке)
